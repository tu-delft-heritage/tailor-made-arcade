# Depot scene generation

Generated with the built-in imagegen tool. Final images are bundled in `src/lib/assets/depot/`.

Reference photos come from the user-supplied [TU Delft IIIF manifest](https://heritage.tudelft.nl/iiif/manifests/ec078729-f33f-4166-be14-1ab7c0a7da4d/manifest.json), credited to Geertje van Achterberg, 2020. The scenes are game illustrations inspired by those views, not exact reconstructions. Canvases inspected: image IDs `573936c0-8d82-486f-9a90-5dd17a9acb5c` (blue racks), `a196bab9-713d-472c-948b-be59054bd661` (compact shelving), and `257b6315-dc5c-464a-9073-9f1c437c78c4` (machinery).

## blue-aisle.png

Use case: stylized-concept. Create a full-bleed 16-bit pixel art background for a nostalgic NES/SNES heritage depot adventure game. Landscape 8:5 composition, approximately 1600x1000 pixels. Reference photograph is atmosphere and architecture reference. Deliberately chunky hard rectangular pixels as if drawn on a 320x200 pixel grid and enlarged nearest-neighbor; coherent limited 24-color palette, deep indigo shadows, muted teal, warm cream and brass highlights. Rich spatial depth and one-point or slightly off-center perspective, hand-pixelled architectural details, readable shelves, no photographic texture, no gradients, no anti-aliasing. Full-room immersive composition, foreground, middle ground, distant aisle. IMPORTANT GAME LAYOUT: horizon at 40% from top. Bottom 35% of the image is a clearly visible open floor with subtle perspective tiles/rails, relatively quiet enough for fallen paper label buttons to be overlaid. At exact horizontal center, create one broad EMPTY cream metal shelf/display ledge at 56% image height, spanning x30% to70%, with unobstructed dark space above it from y18% to54% where the game will place an object photograph. This ledge belongs naturally to the storage furniture, not a separate floating UI panel. Keep strongest clutter around side walls, small objects only on side shelving. Upper 10% relatively dark for small HUD. No people, no characters, no text, no lettering, no labels, no buttons, no frame or screen border, no HUD. Scene: the actual blue metal-rack depot from the reference, a deep aisle with blue sliding cabinets, cream shallow specimen drawers partially pulled out, brass scientific instruments, overhead fluorescent strip lights and exposed ceiling. Warm light at far end. Central empty display shelf integrates into the aisle's end cabinet. Large clear slate-blue floor area in foreground.
